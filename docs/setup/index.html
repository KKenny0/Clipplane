Setup and recovery

The extension chooses. The Host writes.

Chrome extensions cannot safely write ordinary files by themselves. Clipplane uses a small local Native Host to save Markdown and keep credentials in the operating system store.

On this pageAvailabilityInstallDetect and updateFailure statesUninstall

Current availability

macOS-first distribution.Clipplane 0.7.6 publishes a signed, notarized, and stapled Host package for macOS arm64. Windows has no official binary installer; its best-effort path uses the official source and PowerShell setup scripts. Never use third-party Host mirrors or unsigned installers presented as Clipplane releases.

The extension and macOS package are versioned assets on the official GitHub Release. Windows source setup requires Node 20.19 or later in the Node 20 line. Linux, macOS x64, and Windows arm64 are not public 0.7.6 targets.

Install on a supported system

macOS arm64

  1. Download clipplane-host-v0.7.6-macos-arm64.pkg from the official release.
  2. Open the package and complete installation.
  3. Close every browser window, reopen Chrome or Edge, then choose Check again in Clipplane.

Windows x64 from source

  1. Install Node 20.19 or later in the Node 20 line, then download and extract the official v0.7.6 Source code archive.
  2. In that directory run npm ci, followed by npm run setup:windows:chrome or npm run setup:windows:edge.
  3. Close every browser window, reopen Chrome or Edge, then choose Check again.

Windows source setup registers the Host under the current user's HKCU registry and remains best-effort support. Clipplane does not publish a Windows executable or promise SmartScreen reputation.

Detection and updates

The onboarding page checks the Host version and protocol. A successful check means the browser can reach the expected local Host. It does not enable external sync.

On macOS, install the newer signed package over the existing Host. On Windows, download the matching source release, run npm ci, and rerun the setup command. Restart every browser window and check again. Clipplane keeps missing and outdated states separate.

What a failure state means

StateMeaningNext action
Host missingChrome cannot find or connect to the local Host.Install or repair the Host, restart all browser windows, then check again.
Update requiredThe Host answered, but its protocol is older than the extension requires.Install the current matching Host and restart Chrome.
ForbiddenThe Host registration does not allow this extension identity.Reinstall from the matching official candidate. Do not edit the manifest by hand.
Unsupported pageThe browser prevents capture on this surface.Use a normal web page. Internal pages and the Chrome Web Store cannot be clipped.
Consent requiredAn external destination is configured without current per-sink consent.Open Sync settings and review the fields before enabling it.
Note saved, sync failedThe note exists, but the optional external request failed.Keep the note and retry sync. Do not capture again.

Uninstall

The macOS package includes the matching Host uninstall helper. Windows source users run pwsh -NoLogo -NoProfile -File .\scripts\uninstall-native-host.ps1 from the matching source directory. Uninstall removes owned Chrome and Edge Host registrations and deletes Clipplane's Notion and flomo credentials by default; local notes and capture files remain untouched.

Do not include secrets in support reports.If setup still fails, follow the safe report checklist on the Support page. Remove personal paths and configuration values from diagnostic output.
