Clipplane turns a selection, a readable page, or one chosen element into a clean note with its source attached—and a trail you can inspect later.

Notes land in your local inbox by default. Nothing is sent to Notion or flomo unless you configure that destination, consent to it, and choose Save + sync.

Choose the boundary

Three ways to say what belongs.

Ordinary copying loses context. Saving a whole page often keeps too much. Clipplane makes the capture boundary explicit before it writes anything.

01

Selection

Saves the text you highlighted. Best when exact wording matters and the surrounding page does not.

02

Page

Extracts the readable body, keeps useful structure, and removes navigation and page chrome.

03

Element

Lets you point at a card, section, comment, or code block and confirm that region before saving.

From page to note

A note comes first. Sync is a second step.

Clipplane has no account, telemetry service, advertising backend, or Clipplane-operated content cloud.

1. You choose

A click, context-menu action, or confirmed Element selection starts capture.

2. The extension cleans

The active page is reduced to the boundary you requested.

3. The Host writes

A clean note, source details, and an inspectable capture trail stay on your computer.

4. Sync is optional

Only Save + sync can send the confirmed capture to a consented destination.

Current candidate

The interface tells you what actually happened.

Green appears only after a confirmed result. Local success and external sync are reported separately, so a failed sync never hides a safe local copy.

Availability

macOS first. Windows from source.

Clipplane 0.7.6 provides a signed and notarized Host package for macOS arm64. Windows keeps the same local Host and capture features through the official source setup path, but has no public binary installer. The Chrome Web Store item is not public yet.
